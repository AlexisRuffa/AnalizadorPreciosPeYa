Se registran automáticamente las Ahorrames incluidas en el archivo final. El sistema las detecta el mes siguiente para que sepas cuáles ya fueron enviadas.

2. Pre-procesamiento del Archivo 1

Se aplican en orden al hacer click en "Analizar" (nada corre antes):

#FiltroResultado
1 Excluir código 999999
Cualquier código que matchee /^9+$/		 → Hoja Pendientes de catalogar
2 Excluir Punto Caliente
Publicación = CARTEL PUNTO CALIENTE		 → Se descarta completamente
3 Filtro por período
Se conservan solo artículos cuyo rango Desde–Hasta se solape con la semana ingresada		 → Los que no se solapan se descartan
4 Detección de Ahorrames
Publicación = Ahorra mes. El usuario decide mediante un tilde si incluirlos. Las "ya enviadas" este mes se advierten pero no se excluyen automáticamente.		 → Checkbox tildado = incluir todas. Destildado = excluir todas.
5 Deduplicación
• Mismo SKU + mismo combo → quedarse con el que tiene precio > 0
• Mismo SKU + distinto combo → alertar y priorizar Fidelización		 → Alerta visible al usuario
3. Análisis de Fidelizados

Para cada artículo con Combo = Fidelización se busca su par en el Archivo 2 (AS400) por código. La comparación es del Precio Regular del sistema (columna Precio del AS400):

CondiciónDestino
No encontrado en AS400 Pendientes de catalogar — motivo: "No encontrado en AS400"
Precio sistema == PVP Fide (A1) Con error — se cargó el precio fide como precio regular
Precio sistema == PVP Regular (A1) Regular Fidelizados — precio correcto
No coincide con ninguno Con error — obs: "No coincide con el precio en sistema"

Tolerancia: configurable en pesos (default $0 = comparación exacta). Si se configura en $X, los artículos dentro de ese rango van a Fidelizados con observación en lugar de a Con error.

4. Simples y Volumétricas

Se incluyen los artículos del Archivo 1 con Combo distinto a Fidelización (ej: 2x1, 2do al 50%, 30% off, 4x3, etc.), siempre que ese mismo SKU no tenga también una promo Fidelización. Si tiene ambas, solo aparece en Fidelizados.

5. Exclusivas

Se toman del Archivo 3 (Dinamicas Web+App) los artículos que cumplan todas estas condiciones:

  • Su rango Desde–Hasta se solapa con la semana ingresada
  • No son de tipo EO (Especial Ocasión)
  • No tienen otra promo en el Archivo 1 (ni Fide, ni Simple/Vol, ni Ahorrames)
  • Tienen descripción cargada (filas vacías se descartan)
  • Si el mismo SKU aparece varias veces → se toma solo la primera ocurrencia dentro del período

Importante: Los SKUs de Ahorrames bloquean su aparición en Exclusivas aunque el checkbox esté destildado.

6. Pendientes de catalogar

Se acumulan en esta hoja con su motivo:

  • Artículos con código 999999 (código genérico, no catalogados) → motivo: "Código genérico (999999)"
  • Artículos no encontrados en AS400 → motivo: "No encontrado en AS400"

8. Registro de Ahorrames

El sistema lleva un registro mensual en el browser (localStorage) de las Ahorrames incluidas en el archivo final de cada semana.

  • Si una Ahorrames ya fue enviada este mes → se muestra un aviso pero no se excluye automáticamente
  • El checkbox decide todo: tildado = incluir todas, destildado = excluir todas
  • Solo se registran las nuevas al descargar (las que no estaban en el registro del mes)
  • Desde la pestaña Ahorrames: ver listado, descargar en Excel, limpiar al inicio de cada mes
